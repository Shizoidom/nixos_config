Сочетание клавиш,Действие

SUPER + RETURN,Открыть терминал (Kitty)

SUPER + SPACE,Открыть поиск приложений (Fuzzel)

SUPER + Q,Закрыть активное окно

SUPER + E,Открыть файловый менеджер (Dolphin)

SUPER + F,Переключить окно в плавающий режим

SUPER + H / J / K / L,Фокус по окнам в стиле Vim (влево / вниз / вверх / вправо)

Сочетание клавиш,Действие

SUPER + 1 ... 4,Переключиться на воркспейсы 1–4 (Экран ноутбука)

SUPER + 5 ... 6,Переключиться на воркспейсы 5–6 (Внешний монитор)
